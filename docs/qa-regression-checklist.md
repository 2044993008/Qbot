# QA Regression Checklist

这份清单用于验证最近一轮缺陷修复，覆盖聊天、认证、空间动态、设置与敏感接口。

## 1. 认证与登录态

- [ ] 使用正确账号密码登录成功，跳转到 `/app`
- [ ] 使用错误密码登录，看到明确错误提示
- [ ] 刷新页面后仍保持登录态
- [ ] 清空/伪造 `qq_token` 后，请求 `/api/auth/login` GET 返回未认证
- [ ] 未登录访问 `/api/seed` 返回 `401`

## 2. 首页与聊天列表

- [ ] 进入 `/app` 不白屏、不报错
- [ ] 会话列表能正常加载
- [ ] 好友列表能正常加载
- [ ] 群聊列表能正常加载
- [ ] 点击 AI 管家会进入聊天页，不会卡在“加载中...”

## 3. `/app/chat/[id]` 路由解析

- [ ] 通过好友 ID 打开聊天页，显示正确好友昵称/备注
- [ ] 通过群会话 ID 打开聊天页，顶部显示群名且成员数可见
- [ ] 群聊页面出现 `@` 按钮，私聊页面不出现
- [ ] 打开不存在的聊天 ID 时，不应白屏；应停留在安全错误态或日志里仅出现受控错误

## 4. 私聊与群聊消息

- [ ] 私聊发送文本消息成功后，新消息立即出现在列表底部
- [ ] 发送失败时，输入框内容不会丢失
- [ ] 群聊发送消息成功后，消息显示发送者信息
- [ ] 顶部上滑/点击“加载更多消息”能继续拉历史消息
- [ ] 私聊消息接口不能被非拥有该会话记录的用户直接读取

## 5. AI 管家

- [ ] 打开 AI 管家聊天后发送消息，能收到自动回复
- [ ] 在普通好友聊天里发送消息，不会误触发 AI 自动回复
- [ ] AI 管家修改身份/记忆/设置时，不再因为 `user_settings` 唯一约束问题报错

## 6. 好友资料与备注

- [ ] 打开好友资料卡，能看到最近消息与“成为好友”时间
- [ ] 修改备注后，资料卡立即显示新备注
- [ ] 关闭资料卡再打开，备注仍正确
- [ ] 好友列表和资料详情中的时间字段都使用 `friendship_created_at`

## 7. 个人资料页

- [ ] 编辑昵称/签名后保存成功，界面立即刷新
- [ ] 编辑头像颜色后，当前页头像立即刷新为新颜色
- [ ] 刷新页面后颜色保持正确

## 8. QQ 空间

- [ ] 发布纯文本动态成功
- [ ] 发布带图片动态成功
- [ ] 发布失败时，输入框文字和已选图片不会被清空
- [ ] 评论成功后，新评论立刻出现，输入框被清空
- [ ] 评论失败时，输入框内容仍保留
- [ ] 对不存在的 `moment_id` 点赞/评论时，接口返回明确错误而不是 `500`

## 9. 点赞/评论一致性

- [ ] 点赞后 `like_count` 与实际点赞状态一致
- [ ] 取消点赞后 `like_count` 正确回退
- [ ] 重复快速点击点赞，不应出现同一用户重复点赞的脏数据
- [ ] 评论后 `comment_count` 与评论条数一致

## 10. 数据库与迁移

- [ ] 本地执行 `pnpm db:init` 后，`moment_likes(moment_id, user_id)` 存在唯一索引
- [ ] 本地执行 migration SQL 后，`user_settings(user_id, key)` 存在唯一索引
- [ ] 数据库中历史重复数据会在创建唯一索引前被清理

## 11. 静态验证

- [ ] `pnpm exec tsc -p tsconfig.json --noEmit` 通过
- [ ] 不再出现以下已知坏味道：
  - [ ] `group:groups(*)`
  - [ ] `conversation.target_id === userId` 私聊鉴权
  - [ ] `onConflict: 'user_id,key'`
  - [ ] `friend_since`
  - [ ] `decodeToken()` 被认证入口调用
